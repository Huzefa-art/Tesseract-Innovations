# 🧠 Agentic AI Chatbot

This project is an agent-based chatbot. Follow the instructions below to set up and run the project.  
You will need access to the **ChatGroq API**.


## ⚙️ Setup and Run Instructions

Make sure you have **Anaconda** or **Miniconda** installed before proceeding.

### 1. Create and Activate Conda Environment

conda create -n agentic_ai_chatbot python=3.12
conda activate agentic_ai_chatbot

## 2. Install Python Dependencies
pip install -r requirements.txt

## 3. Run the Chatbot
python Agents.py
